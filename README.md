# Frontel

**Build visually. Preview instantly. Own the code.**

Frontel is a visual frontend-building project created to explore and demonstrate interactive UI development, visual editing workflows, and frontend engineering.

It provides a canvas-based environment where users can arrange interface elements, manage layers, customize properties, and preview their designs.

> **Important:** Frontel is a portfolio project. It was developed to demonstrate frontend development capabilities, experimentation, and implementation skills. It is not presented as a production-ready commercial product or a fully supported website builder.

## What It Demonstrates

Frontel showcases several aspects of frontend development:

* **Visual Interface Development** — Building an interactive, canvas-based editing environment.
* **Drag-and-Drop Interactions** — Allowing elements to be positioned and manipulated visually.
* **Layer Management** — Organizing interface elements through a structured layer tree.
* **Property Editing** — Providing controls to inspect and customize selected elements.
* **Multi-Page Workflows** — Managing different pages within a project.
* **Reusable Sections** — Exploring component reuse and structured interface composition.
* **Live Preview** — Viewing design changes through a preview workflow.
* **Visual Customization** — Working with themes, effects, and assets.
* **Code Export** — Exploring the connection between visual design and generated frontend code.

## Key Features

* Interactive visual canvas
* Drag-and-drop editing
* Layer tree
* Selection inspector
* Multiple pages
* Reusable sections
* Asset management
* Visual effects
* Multiple themes
* Design, Source, Preview, and Export workflows
* Starter templates

## Project Purpose

Frontel was built to explore the challenges of creating a visual frontend editor.

The project demonstrates an understanding of interactive interfaces, UI architecture, component organization, state management, and the relationship between visual editing and frontend code.

It also shows how to take an idea from concept to a working software project.

## Project Status

**Portfolio project — Experimental**

Frontel is not intended to compete with established professional website builders. Its purpose is to showcase development work and technical experimentation.

Features may be incomplete, experimental, or subject to change.
